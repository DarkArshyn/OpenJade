# Restored sky and moon — 2026-10-30

## Scope

Restore two previously rejected scaled objects from the frozen menu.
No global lighting, gamma, fog density or camera change. Existing balcony x2
remains disabled. This does not implement the separate LUM_Lune light.

| Object | Key | Triangles | Local-axis scale |

## Material states

Sky material 30000CAC has flags 0x00006007: opaque, depth writes enabled,
no alpha test, linear repeat sampling, selector 3 (geometry colors).
Its mesh contains geometry RGB but no instance RGB. The sky pass applies
texture * geometry RGB * 2, with no global multiplier.

Moon material 30000D1B (source slot 32), texture 68000DAC, has flags
0x00014607: source alpha / inverse source alpha, depth writes disabled,
no alpha test, linear repeat sampling, selector 2 (constant color).
Its constant RGB is (86,102,118); vertices carry twice that normalized RGB.
The fragment gain stays 1 to avoid multiplying twice. Local alpha is
128/255 from packed word 0x80000000, multiplied by texture alpha.
Both states use the decoded identity UV fallback (U word zero, V 0x3F800000).

The same sky material is also used by Menu3D_ground.gao. New state application
is deliberately restricted to the restored sky/moon objects: the ground and
all previous draw parameters are preserved. The software preview uses
per-object texture overrides for the same reason.

Native evidence: 00441560 color/alpha selection and 006696B0 material states
in local reports/native-fog-20261021/evidence; packed words from the frozen
resource, SHA-256
`96244fe330c11acdf2a87a7c8a410225b224f5f1b9f264834425848cbf4d00eb`.

## Transparency and format

The exporter emits opaque passes first, then transparent passes sorted back
to front by group-center depth at initial Camera02. Stable sorting retains
stage order within each fixture. Vertex ranges are repacked to remain
contiguous as required by the existing OJSCN003 reader.

This improves the initial composition but is not recovered native sorting.
The exported order is fixed. The subsequent
[camera-relative runtime update](2026-10-30-camera-transparency.md) re-sorts
passes during playback; overlapping transparent surfaces remain a limitation.
No renderer format or shader changes are required.

## Validation

- Final package: 48 objects, 15,813 geometry triangles, 16,365 submitted
  triangles, 90 passes and 39 image layers.
- Four sky tests cover material states/local alpha, rejected unknown rotation,
  scale-before-rotation, exported blend/depth, single constant gain and the
  unchanged ground sharing the sky material.
- Existing material-export regressions pass.
- Real-data comparison checks original texture hashes, camera hash and
  previous per-draw parameters against the preceding 46-object package.
- Vulkan final-package smoke with native UI, settings, resize and Camera02:
  80 presented frames, zero validation errors on the current AMD adapter.

Initial-camera projection of moon texture center (UV .5,.5): approximately
(216.23,31.09) in the 800x600 viewport. A ray at pixel (216,31) finds opaque
palm4 at depth 4.6441 and palm1 around 15 before the moon at 46.8595; sky is
farther at 79.1123. The moon center is therefore occluded in this reconstruction.
Submission does not imply the full lunar disk must be visible. No repositioning
was done to force visibility. This does not prove exact original-game occlusion.

## Prepare and launch

From the repository root, with new output directories:

```powershell
python src/assemble_menu_scene.py reports/menu3d-focused-4d627a9470c84b73bfc16ae467514310/FF000CB9-decoded/decoded.bin reports/menu-sky-moon-20261030/source-final --yaw 0 --pitch 0 --fov 59.37908
python src/export_engine_materials.py reports/menu-sky-moon-20261030/source-final reports/camera02-transition-20261026/preview/poses.json reports/menu-sky-moon-20261030/runtime-final
```

The runtime exporter takes the validated Camera02 pose from poses.json; the
assembler's camera options affect only its diagnostic software preview.

From engine/:

```powershell
cargo run -p jade-viewer -- --scene ../reports/menu-sky-moon-20261030/runtime-final/menu.ojscene --menu ../reports/engine-ui-scale-20261029/menu.ojui --color-pipeline legacy-unorm --validation
```

Earlier intermediate runtime/runtime-v2 packages in the local report directory
are superseded; use runtime-final. Original game resources remain unmodified.
