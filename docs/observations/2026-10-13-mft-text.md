# Experimental MFT text specimen — 2026-10-13

The independent PowerShell 5.1 command `tools/Export-MFTTextPreview.ps1` now
assembles printable ASCII text from extracted MFT glyphs. The default specimen
is `Nouvelle partie`. This is a research rendering, not a validated recreation
of the menu. No original-game screenshot comparison has been performed.

## Explicit hypotheses

- Crop each glyph at AtlasX + 1, AtlasY + 1, using its Width and Height.
- Interpret Metric2Raw as a signed horizontal bearing.
- Interpret Metric3Raw as a signed distance from the baseline to the top.
- Interpret Metric4Raw as an unsigned pen advance, including for spaces.
- Use raw atlas values as white alpha coverage with source-over blending.
- Apply no kerning, scaling, shadow, color transform or MGM layout.

The size-36 A, g, j, p and exclamation glyphs have visible pixels inside that
crop; the space has no visible pixels. This supports experimenting with this
crop, but does not establish the game's texture sampling rule. Across all
2,688 records, 147 outer rectangle borders contain nonzero pixels; a universal
empty-border rule therefore cannot be asserted.

The initial size-36 specimen is legible on visual inspection. Its canvas is
437x58 pixels including margins, with a baseline at y=42. These are this tool's
dimensions, not the menu's dimensions. The diagnostic PNG adds a blue baseline
and dark background; the text PNG has a transparent background.

## Reproduction

From the repository root:

```powershell
.\tools\Export-MFTTextPreview.ps1 -Path '.\reports\POPData-extracted\menu\fonts\atlantis mf regular 36.mft' -OutputDirectory '.\reports\text-36' -Text 'Nouvelle partie'
.\tests\Test-MFTTextPreview.ps1 -FontDirectory '.\reports\POPData-extracted\menu\fonts'
```

The destination must be new. `ExtraSpacing` permits explicit spacing experiments
and is recorded in specimen.json. Inputs are read-only. Outputs include the full
source copy, SHA-256 provenance, text.png, preview.png and placements.csv with
record offsets, crop coordinates, pen positions and glyph positions.
Only ASCII 32-126 is accepted; extended mappings remain unverified.

Validation: 39 checks under Windows PowerShell 5.1, including an independently
constructed glyph fixture with negative bearing, explicit space advance, crop
pixels, partial alpha, overlap blending, spacing, blank text, overwrite refusal,
unsupported characters, and specimens for all twelve real fonts. Source hashes
were unchanged. The existing 59-check MFT suite also remains applicable.

Next: compare a capture of the original menu at a known resolution against the
specimen, then test the MGM font size, text placement, scaling and color. Until
then, baseline and advance semantics remain hypotheses.
